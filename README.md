# Currency Converter

A simple currency converter built with React and Vite as part of my front-end development learning journey.

## Features

- Convert amounts between USD, EUR, GBP, and JPY.
- Select the source and target currencies.
- Update the conversion when the amount or currency selections change.
- Display a clean, user-friendly interface.

## Built With

- React
- JavaScript
- CSS
- Vite

## Concepts Practiced

- React components
- `useState` for managing state
- `useMemo` for calculating converted amounts
- Handling user input with controlled inputs
- Importing and exporting components
- Git and GitHub workflow

## Getting Started

To run this project locally:

1. Clone this repository.
2. Open the project folder in your terminal.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## Note About Exchange Rates

This project uses predefined exchange rates for practice. The rates are examples and are not updated using a live currency exchange API.
